24. START TENSORFLOW SERVING
----------------------------
docker run -d \
  --rm \
  --platform linux/amd64 \
  -p 8501:8501 \
  -v "$PWD/mnist_outputs/mnist_saved_model:/models/mnist" \
  -e MODEL_NAME=mnist \
  --name mnist-serving \
  tensorflow/serving

Explanation:
- -d: Runs the container in detached/background mode.
- --rm: Removes the container after it stops.
- --platform linux/amd64: Runs the compatible Linux image.
- -p 8501:8501: Connects host port 8501 to container port 8501.
- -v: Mounts mnist_outputs/mnist_saved_model as /models/mnist in the container.
- -e MODEL_NAME=mnist: Names the served model "mnist".
- --name: Gives the container a convenient name.
- tensorflow/serving: Uses the TensorFlow Serving image.

Model endpoint:
http://localhost:8501/v1/models/mnist

Prediction endpoint:
http://localhost:8501/v1/models/mnist:predict

26. SEND A REAL MNIST IMAGE TO THE SERVER
-----------------------------------------
./ml_env/bin/python - <<'PY'
import json
import urllib.request
import tensorflow as tf

(_, _), (images, labels) = tf.keras.datasets.mnist.load_data()
image = (images[0].astype('float32') / 255.0).tolist()

body = json.dumps({'instances': [image]}).encode('utf-8')
request = urllib.request.Request(
    'http://localhost:8501/v1/models/mnist:predict',
    data=body,
    headers={'Content-Type': 'application/json'},
)

with urllib.request.urlopen(request, timeout=30) as response:
    result = json.load(response)

probabilities = result['predictions'][0]
predicted_digit = max(range(10), key=lambda digit: probabilities[digit])

print('Actual digit:', int(labels[0]))
print('Predicted digit:', predicted_digit)
print('Confidence:', f'{probabilities[predicted_digit]:.2%}')
PY

Explanation:
1. Loads one test image from MNIST.
2. Converts pixel values from 0-255 to 0.0-1.0.
3. Sends the image as JSON to TensorFlow Serving.
4. Receives ten probabilities.
5. Selects the largest probability as the predicted digit.

Observed result:
Actual digit: 7
Predicted digit: 7
Confidence: 99.67%
